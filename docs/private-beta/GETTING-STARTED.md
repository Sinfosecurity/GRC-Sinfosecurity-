# Private Beta Getting Started

Supreme Third Party is the active private-beta product. Other named products stay Preview or Roadmap.

1. You receive a unique activation link. Do not share it.
2. Set your own password and sign in.
3. Home shows what needs attention and a Getting started path.
4. Add a vendor, assess it, attach evidence, track findings, make a Decision Brief, then report.
5. Use Help & Support to send feedback.

This environment is **PRIVATE BETA / TEST**. It is not production. Use invented company and vendor names only.
